# 검증 기록

검증일: 2026-11-07 / 로컬 Python 3.14.0.

## 자동 검사

명령: `python -m unittest discover -s tests -v`

10개 테스트 모두 통과했다. 하나의 무작위 검사 안에서 고정 시드 20261107로 100개 데이터를 만들고, 각 데이터에서 A-Priori와 PCY(버킷 1, 2, 5, 101)의 최대 3개 항목집합을 별도 전수계산과 대조했다.

그 밖에 손계산 빈도, 해시 충돌에 의한 거짓 후보 제거, 비트맵 바이트 올림, 중복 제거, 빈 바구니 분모, 최소 지지도 올림, 빈 입력, 규칙 필터 탈락, 삼중항 가지치기·6방향 규칙, 파일 저장·읽기와 실험 보고서 생성을 확인했다.

## CLI 실행

- 예제 주문 행 CSV → A-Priori: 바구니 8개, 빈발 쌍 3개, 기본 필터 규칙 6개.
- 예제 JSON → PCY, 최소 횟수 2, 버킷 5, max_size 3: 빈발 쌍 5개, 빈발 삼중항 2개, 기본 필터 규칙 16개.
- 예제 비교: 지지도 0.375/0.25 × A-Priori 및 PCY 버킷 1/5/101 = 8행 생성. 최종 항목집합 일치.

## 실제 TXT 어댑터 확인

이전 대화에서 다운로드해 둔 SPMF Retail 파일의 첫 1,000개 장바구니만 표본으로 사용했다. 지지도 0.02/0.01, PCY 버킷 101/65521, 반복 1회로 실행해 6행의 비교 결과를 만들었고 두 알고리즘의 최종 결과가 일치했다.

이는 데이터 로딩과 실행 연결을 확인한 스모크 검사다. 표본 추출은 앞 1,000줄 고정이며 시간 검증이나 모집단 대표 표본이 아니다. 반복 1회인 이 결과를 성능 우열의 증거로 사용하지 않는다.

로컬 결과: `outputs/retail_smoke/report/`. 공유용 ZIP에는 이 실데이터 표본과 생성 결과를 포함하지 않는다.

## 아직 확인하지 않은 범위

- UCI Online Retail II 전체 데이터 성능과 최종 보고서 수치
- 팀 저장소의 기존 API·반환 형식과의 연결
- Solar 에이전트, 고객별·기간별 평가
- 수 GB 규모의 데이터, 디스크 기반·분산 실행

검증 시점에는 기존 팀 코드를 변경하거나 원격 저장소에 Push하지 않았다. 이후 공유 시 이 폴더만 별도로 추가한다.

## 2026-11-09 팀 API 연결 검증

Hyeonseop 브랜치에서는 src/apriori.py 및 src/pcy.py를 이 모듈의 호환 어댑터로 교체했다.
독립 테스트 10개와 새 연결 테스트 2개가 통과했다. 기존 팀의 test_textbook, test_pcy_hash,
test_evaluate 및 test_answer_key 실행도 모두 통과했다. 기존 PCY 비트맵 이론 공간 검사의
바이트 내림을 올림으로 수정했다. 기본 Lift > 1 정책과 기존 평가·Solar 호출 형식을 유지한다.
전체 UCI 데이터 재실행이나 Solar API 호출은 수행하지 않았고 기존 결과 CSV·그래프도 변경하지 않았다.
